## Overview

Designed and built an autonomous weeding robot for the **e-Yantra Robotics Competition (EYRC) 2022** organized by IIT Bombay. The robot navigates an agricultural arena, identifies weeds versus crops using computer vision, and performs targeted weeding operations autonomously.

## Key Features

- **Weed Detection** — Vision-based classification to distinguish weeds from crops in the arena
- **Precision Weeding** — Targeted mechanical actuation to remove weeds without damaging surrounding crops
- **Autonomous Navigation** — Path planning through crop rows with obstacle avoidance
- **Mechanical Design** — Custom-designed chassis and weeding mechanism optimized for the competition arena, recognized with the Best Mech Award
